# Datheon Data Analytics & Power BI Internship

A collection of end-to-end data cleaning, exploratory data analysis (EDA), and business intelligence visualization projects completed during my Data Analytics & Power BI Internship at **Datheon**.

---

## Repository Structure

| File | Description |
| :--- | :--- |
| `Daethon_Task1_Superstore_EDA.ipynb` | Python Jupyter Notebook covering data cleaning, preprocessing, and exploratory data analysis. |
| `Task_1_superstore_sales.csv` | Raw Superstore sales dataset used for Task 1. |
| `Task_1_superstore_cleaned.csv` | Processed and cleaned dataset exported after handling missing values, formatting, and anomalies. |
| `Task_1_superstore_eda_results.xlsx` | Summary tables and statistical findings exported from the EDA phase. |
| `Task_2_superstore_sales.csv` | Dataset utilized for building the Power BI dashboard. |
| `Task_2_Superstore_Dashboard .pbix` | Interactive Power BI report visualizing KPIs, regional performance, and sales trends. |

---

## Project Breakdown

### Task 1: Superstore Exploratory Data Analysis (Python)
* **Objective:** Clean raw retail transaction data and uncover actionable trends across product categories, customer segments, and geographic regions.
* **Key Steps:**
  * Handled missing values, duplicate records, and inconsistent date/data types.
  * Analyzed profit margins, discount impacts, and top-performing sub-categories.
  * Exported cleaned datasets (`Task_1_superstore_cleaned.csv`) and structured Excel summaries (`Task_1_superstore_eda_results.xlsx`) for downstream reporting.

### Task 2: Superstore Sales & Profit Dashboard (Power BI)
* **Objective:** Design an interactive executive dashboard to monitor business performance and support data-driven decision-making.
* **Dashboard Highlights:**
  * **KPI Tracking:** Total Sales, Total Profit, Profit Margin %, and Order Volume.
  * **Trend & Regional Analysis:** Monthly/yearly sales trajectories and regional profitability breakdowns.
  * **Interactive Filtering:** Dynamic slicers by Category, Sub-Category, Segment, and Region.
